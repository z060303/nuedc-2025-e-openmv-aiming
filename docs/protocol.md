# 串口协议与控制计算

## OpenMV → STM32

OpenMV 使用 UART3、115200 波特、8N1，每帧发送三个十进制整数及末尾空格：

```text
x y flag 
```

例如 `174 105 1 ` 表示检测到红色目标，其中心在画面 `(174,105)`。坐标是 **QVGA 像素**，并非角度、毫米或世界坐标。`flag=0` 时脚本发送 `0 0 0 `。OpenMV 目前选取像素面积最大的红色色块，阈值为 `red_threshold=(16,41,14,41,4,44)`，`pixels_threshold=400`。

STM32 从 USART2/PA3 的 DMA 缓冲区接收，利用 UART 空闲中断识别一帧，用 `sscanf` 解析三元组并检查 `0≤x<320`、`0≤y<240`、`flag∈{0,1}`。源码中虽有自适应 IIR 滤波函数，但调用被注释，实际发送的是未经滤波的色块中心。发送端没有显式换行符；如果多帧合并或串口干扰，接收端可能无法正确分帧。协议升级时最好同时修改两端，加入帧头、长度或换行、校验和及超时处理。

## STM32 内部计算

参考中心是 `(160,120)`。当 `flag=1` 时，X 和 Y 各自调用 `PID_Update()`：

```text
error_x = 160 - x
error_y = 120 - y
output = Kp × error + Ki × 累积误差 + Kd × (本次误差 - 上次误差)
```

X 轴输出先限制在 `[-200,200]`，再补偿最小启动速度、做一阶低通滤波；发送给步进驱动器的速度约为滤波后绝对值的 1/10。X 误差在 ±2 像素内时直接发停止指令。Y 轴输出通过 `PitchServo270_Turn()` 更新舵机角度，限制在 50°～270°，并换算为 PWM 比较值。上述方向与实际电机布置相关，必须在空载时确认。

## STM32 → 步进驱动器

USART1/PB6 TX 按原工程使用的 Emm V5 速度命令发送 8 字节：

```text
[地址, 0xF6, 方向, 速度高字节, 速度低字节, 加速度, 同步标志, 0x6B]
```

当前调用地址为 `1`，加速度参数 `10`，同步标志 `0`。仓库只实现这一个命令，其他电机配置仍需按所用驱动器手册操作。STM32 不读取驱动器回复，不能据此判定电机已经到位。
