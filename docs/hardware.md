# 硬件接线与联调

本说明对应 2025 年电赛 E 题“简易自行瞄准装置”的**瞄准模块**。赛题中的 MSPM0 寻迹小车、蓝紫激光笔及其独立供电控制不在这两份源代码中，接线表只覆盖已提供的 OpenMV 和 STM32 云台链路。

## 实际硬件链路

| 信号 | STM32F103 引脚 | 对端 | 用途 |
| --- | --- | --- | --- |
| OpenMV 串口 TX | PA3 / USART2 RX | OpenMV UART3 TX | 接收目标像素坐标 |
| 电机控制 TX | PB6 / USART1 TX（重映射） | Emm V5 兼容驱动器 RX | 水平轴速度命令 |
| 舵机 PWM | PA9 / TIM1 CH2 | 俯仰舵机信号线 | 俯仰角控制 |
| 调试输出 TX | PB10 / USART3 TX | 串口调试器 RX（可选） | `printf` 日志 |
| 地线 | GND | OpenMV、驱动器、舵机电源 | 共同参考地 |

OpenMV UART3 对应的实际插针随板型变化。所有串口信号接线前确认双方 TTL 电平兼容；不要把 5 V TX 直接接到只容许 3.3 V 的输入。步进电机和舵机使用符合其额定电压、电流的独立稳定电源，不从 STM32 GPIO 直接供电。具体电机型号、机械限位和电源规格未由这些代码确定。

## 联调步骤

1. 用 OpenMV IDE 的阈值编辑器重新调 `red_threshold`，确保仅目标被框住。图像是 320×240，屏幕中央十字应接近 `(160,120)`。
2. 不接电机，确认 STM32 收到 `x y flag`，目标丢失时 `flag=0`。USART2 为 115200/8N1。
3. 只接水平轴驱动器，确认电机地址 `1`、波特率和命令格式匹配。先用低速度，检查误差正负时方向是否正确。
4. 只接俯仰舵机，确认 PA9 的脉宽与舵机规格相符。原始 TIM1 配置为 1 MHz 计数、40 ms 周期，控制范围约 500～2500 μs，须按舵机数据表核对。
5. 两轴合用时从小增益开始，检查机械行程、线缆余量和电源压降。完成后再调 PID 参数与色块阈值。

## 常见问题

| 现象 | 核查点 |
| --- | --- |
| OpenMV 能识别但云台不动 | UART3 TX→PA3、共地、115200、三元组完整性 |
| 云台越跟越偏 | X/Y 轴接线与控制正负方向、相机安装方向 |
| 步进轴抖动 | 阈值噪声、±2 像素死区、PID、驱动器最小速度 |
| 舵机跳动或不在中位 | TIM1 周期和脉宽、舵机供电、零位范围 |
| 丢失目标后仍移动 | 是否收到 `flag=0`、空闲中断分帧是否成功 |

工程没有机械限位开关与上电回零流程；长期无人看守运行前需要补齐限位及失联保护。
